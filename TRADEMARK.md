# Moondial trademark policy

The Moondial code is licensed under Apache-2.0, which grants rights to the code and, in its section 6, no rights to the name. "Moondial" and the Moondial logo (when there is one) identify this project and the software this project releases. This policy says what you may do with them without asking.

## You may, without asking

- Use "Moondial" to refer to this project and to unmodified builds of it.
- Say that your world, module, client or service is "built on Moondial", "runs on Moondial" or "compatible with Moondial", when it is.
- Use the name in articles, talks, tutorials and reviews, including critical ones.
- Keep the name in forks on GitHub that exist to contribute changes back.

## Please ask first, or pick another name

- Distributing a modified version of the engine under the name "Moondial". A fork that changes the driver's behavior should be called something else, with "based on Moondial" if you like.
- Using "Moondial" or a confusingly similar name as the name of your own product, service, company, domain or crate.
- Using the name or logo in a way that suggests the project endorses you, your world or your company.

## Why

The license makes the code free for everyone. The name is what tells people which code they are getting. Keeping the two separate is how every open-source project with a name people trust (Rust, Godot, Kubernetes) stays trustworthy.
